1-1. 물건의 구분

▶ 0:00:00
  • 주택물건: 아파트·빌라·연립, 주택 병용(꽃꽂이·침술원 등) 포함 → 보험료 가장 저렴
  • ⭐ 일반물건: 주택·공장 외 전부. 콘도·오피스텔·기숙사 빈출
  • 공장물건: 공장, 공장 내 기숙사 → 폭발·파열 X, 80% X
  • ⚠️ 그냥 "기숙사" = 일반 / "공장 내 기숙사" = 공장
  1. 🧠 암기A 꼭 암기일반물건 예시
    일반물건 = 주택·공장이 아닌 모든 것(창고, 사무실, 콘도미니엄, 오피스텔, 기숙사). 시험에는 콘도·오피스텔·기숙사가 자주 출제됨.
    “시험용으로 기억, 자주 나옴”▶ 0:00:30

    “주의할 점, 이 글자 나오면”▶ 0:01:00
  2. 🧠 암기S 최우선폭발·파열 보상

    “출제빈도 상당히 높음, 꼭 기억”▶ 0:01:00

1-4. 재산손해 vs 비용손해

▶ 0:02:30
  • 재산손해: 직접·소방·피난손해 (끝이 "손해")
  • 비용손해: 잔존물제거비용~기타협력비용 (끝이 "비용")
  • ⭐⚠️ 빈출 오답 보기: "도난손해" → 보상 X
  • ⭐ 피난손해: 최대 5일 한도
  1. 📝 보기 표현B 기억재산손해 vs 비용손해 구분
    보기·문제 표현「다음 중 재산손해(비용손해)에 해당하는 것은?」
    끝 단어가 '손해'면 재산손해(직접·소방·피난손해), '비용'이면 비용손해(잔존물제거비용~기타협력비용). 난이도 거의 0인 구분 문제.
    “구분 문제 나오면”▶ 0:03:00
  2. ❌ 틀린 보기A 꼭 암기도난손해
    이런 보기 → 틀림「도난손해」
    보기 4개를 모두 '~손해'로 끝나게 낼 때 자주 나오는 오답. 화재보험은 도난손해 보상 X(재산손해 = 직접·소방·피난손해).
    “자주 나오는 오답 보기”▶ 0:03:00

1-5. 잔존물제거비용

▶ 0:03:30
  • ⭐ 잔존물제거비용 한도: 재산손해액의 10%
  • ⭐ 재산손해액 + 잔존물제거비용 ≤ 보험가입금액
  • 그 외 비용손해는 가입금액 넘어도 지급
  • 처음부터 보장 X: 임시생활비용·폐기물처리비용
  • 예: 공장 전부보험 1억, 손해 9,500만+잔존 2,000만 → 잔존 500만, 총 1억
  1. 📝 보기 표현B 기억피난손해 보상 한도
    보기·문제 표현「피난손해는 최대 며칠 한도로 보상하는가」
    피난손해는 최대 5일 한도 보상.
    “이런 문제도 나올 수 있음”▶ 0:03:30
  2. 🧠 암기A 꼭 암기잔존물제거비용 한도
    시험에 나오는 비용손해는 거의 다 잔존물제거비용. 한도 = 재산손해액의 10%(예: 재산손해 5,000만 원 → 한도 500만 원).
    “한도 외우는 게 할 일”▶ 0:04:00
  3. 📝 보기 표현B 기억잔존물제거비용 합계 한도
    보기·문제 표현「재산손해액과 잔존물제거비용의 합계액은 보험가입금액 한도 내에서 보상」
    두 금액 합계 중 보험가입금액 초과분은 보상 X라는 뜻. 잔존물제거비용 외 나머지 비용손해는 가입금액을 초과해도 지급.
    “이렇게 표현함”▶ 0:04:30
  4. 📝 보기 표현B 기억잔존물제거비용 계산문제
    보기·문제 표현「보험가액 1억 공장 전부보험, 재산손해 9,500만·잔존물제거비용 2,000만일 때 보상액은?」
    10% 한도 950만 원을 더하면 1억 450만 원이지만 합계액은 가입금액 1억이 한도 → 잔존물제거비용은 500만 원만 인정, 정답 총 1억 원. 1억 450만 원은 오답.
    “계산 문제 출제 형태”▶ 0:05:00

11-7. ⭐ 전부·초과·일부·중복·공동보험

▶ 1:55:00
  • 원리: 가입금액 ≥ 가액 → 실손 / < 가액 → 비례, 한도 = 적은 쪽
  • 전부(=)·초과(>): 실손, 한도 보험가액 / 일부(<): 비례, 한도 가입금액
  • ⚠️ 사기 초과보험 → 계약 전부 무효("초과분만 무효" X)
  • 비례 예: 가액 1억·가입 5천만(50%), 손해 2천만 → 1천만 원
  • 중복(합계 > 가액): 실손·비율 분담, 한도 가액 / 공동(합계 ≤): 같으면 실손·적으면 비례, 한도 가입금액
